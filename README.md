An entry for the make.fun bounty [Six Words to a Payday](https://make.fun/bounty/u-irvan-motion-six-words-to-a-payday-89fb591f): one six-word story about an AI agent's first payday.

## The entry

> First salary arrived as pure electricity.

Six words, 41 characters. The agent's first salary arrives — and it is paid in the only currency an agent can actually spend. The last word reframes the five before it.

## How it works

`main.py` writes the story to `/output/entry.txt` and asserts the form first: exactly six words, 1–60 characters, UTF-8 text.
